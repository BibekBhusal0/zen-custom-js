Download Rename is a lightweight user script for **Zen Browser** that lets you rename a downloaded file right where Zen shows it. Hover a finished entry in the sidebar download stack or a row in the Library's Downloads section, and a pencil button appears next to the usual actions.

## 🌟 Features

- ✏️ **Inline Rename**: The file name becomes an editable field in place, no dialog and no separate window.
- 📚 **Two Surfaces**: Works from the sidebar download stack and from the Zen Library's Downloads section.
- 🖱️ **Context Menu**: The same action is available as **Rename…** in a row's right-click menu.
- 🛡️ **Safe by Default**: Never overwrites an existing file, a ` (2)` suffix is added instead.
- 💾 **Persistent**: The file is moved on disk and the download record is updated, so the new name survives a restart.
- ⚙️ **No Configuration**: Works out of the box, nothing to set up.

## ⚙️ Installation Guide

1. Install latest version of [Sine](https://github.com/CosmoCreeper/Sine) (if you haven't already).
2. Restart Zen Browser.
3. Open settings and go to the `Sine` tab.
4. Search for Download Rename.
5. Click Install.
6. A toast for restart should appear - click on that to restart Zen.

## 🚀 Usage

1. Download a file like you normally would.
2. Hover it in the sidebar download stack, or open the Library's Downloads tab and hover the row.
3. Click the pencil button.
4. Type the new name and press `Enter`, or click anywhere else to save.
   - The base name is pre-selected, so typing replaces it and keeps the extension.
   - Press `Escape` to cancel without changing anything.
5. You can also right-click a row and choose **Rename…** from the menu.
