# New Features

- Press Tab / Shift+Tab in the menu to jump between Recently Closed, Open Tabs, and Synced Tabs. Empty or disabled sections are skipped.
- Tab search now uses fuzzy matching and sorts by relevance, same as the command palette.
- Cleaner group headers with tab counts, plus a friendlier empty state.

# Fixes

- Long tab titles and descriptions no longer overflow or overlap the icons.
